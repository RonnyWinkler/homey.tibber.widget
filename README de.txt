Diese App erweitert dein Homey Dashboard um ein praktisches Widget für die Tibber App. 

Das Widget zeigt ein Diagramm der aktuellen Strompreise sowie den Live-Verbrauch deines Tibber Pulse Stromzählers. 
So behältst du deinen Energieverbrauch und die Stromkosten jederzeit im Blick – direkt auf deinem Homey Dashboard!

Voraussetzung:
- Tibber App ab Version Version 1.10.0 - currently test version
- Tibber Pulse device for Energy data (smart meter)
- Tibber Home device for price data and chart
